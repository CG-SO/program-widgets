# AGENTS.md — cg-so/program-widgets

Static embeddable widgets for cgiar.org program pages (map + connections diagram + goals). Hosted on GitHub Pages, embedded in Drupal via iframe. Read README.md first.

## Rules
- No build step, no framework. Plain HTML/CSS/JS. Leaflet is vendored in `vendor/leaflet/`.
- Colours live in `assets/widgets.css` only. Brand greens only (#033529, #06604b, #18f2be, #58fbd4, #e6fff9); no brown/tan.
- `data/portfolio.json`, `data/program-maps.json` and `data/program-goals.json` are generated by `tools/sheet_to_json.py` from the comms workbook. Change the workbook, not the JSON, unless told otherwise.
- Program text comes from cgiar.org verbatim. Do not rewrite content.
- The workbook (`*.xlsx`) is never committed (it holds comms contacts and notes). It is in `.gitignore`.
- Bump `?v=` on asset URLs in the HTML files whenever an asset changes.
- Accessibility: keyboard-operable controls, `aria-pressed` on toggles, visually hidden text summary, reduced-motion respected, 3:1 contrast for map fills.

## Git
- Default branch `main`, GitHub Pages serves `main` root.
- Never force-push. Ask Dodi before creating the repo, pushing, or changing Pages settings.
- One commit per logical change; Pages deploys can queue if you push many commits quickly.
