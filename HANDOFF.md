# Handoff to Claude Code: cg-so/program-widgets

From: Claude (Cowork session, 2026-11-16) · Owner: Dodi

## Goal
Publish this folder as the public repo **cg-so/program-widgets** with GitHub Pages, so the program pages on cgiar.org can embed:
- `https://cg-so.github.io/program-widgets/program-map.html?program=<id>&id=programMap`
- `https://cg-so.github.io/program-widgets/portfolio-diagram.html?focus=<id>&id=portfolioDiagram`

Same pattern as `cg-so/apac-map` and `cg-so/where-cgiar-works` (JSON content, iframe embed, height via postMessage). No Drupal code or feature branch needed.

## What is here
- `program-map.html` + `assets/program-map.js`: map engine. Handles any mix of global / regions / countries / tiers per program.
- `portfolio-diagram.html` + `assets/portfolio-diagram.js`: "Interlinked support across CGIAR's portfolio" diagram. Use `?focus=<id>` on a program page, or no focus for the portfolio overview.
- `index.html`: preview of every program, with copy-ready embed code.
- `data/*.json`: content. `program-maps.json` and `portfolio.json` are generated by `tools/sheet_to_json.py` from `CGIAR_program_connections.xlsx`, which is in this folder and NOT to be committed.
- `README.md`: full docs (data format, embed snippet, regions dictionary).
- `AGENTS.md` / `CLAUDE.md`: repo rules.

5. **Embed test:** make a scratch HTML page that embeds both widgets with the snippet from README.md. Check that the auto-height works and that two widgets on one page don't resize each other.
